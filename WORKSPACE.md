# Workspace integration

This fork adds [a native Workspace package](integrations/workspace/README.md)
with MyAccounts login, same-origin `/git/` hosting, bundled Git, isolated
repository storage and protected recovery. Build with
`integrations/workspace/build.ps1` or install it through the Git and Music
edition of [One Workspace](https://github.com/fahimc/one-workspace).

The package uses Gitea's unchanged official 28.1.0 executable and an independent
source-available launcher. The upstream application and development source are
retained here with their original licenses.
